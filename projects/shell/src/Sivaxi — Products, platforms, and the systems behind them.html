    What Sivaxi builds

    Software across the stack, from the interface people use to the services and automation behind it. These are our areas of work and the kind of output each produces.

      How we work

      The same loop applies to our own products and to collaborations, so results stay predictable.

        Engineering practices

        • Open where it helps. Source and progress live on GitHub.
        • Accessible by default. Keyboard navigation, visible focus, and contrast checks are part of every interface.
        • Incremental releases. Small, reviewable changes instead of large rewrites.
        • Decisions written down. Trade-offs end up in the journal, not in someone's head.

        Technology we use

        Current front-end foundations of the Sivaxi web platform. Backend and infrastructure choices are documented as they settle.

        • Angular
        • Native Federation
        • TypeScript
        • Tailwind CSS
        • REST APIs
        • Git & CI

        Designed as one system

        Every interface draws from shared tokens: one accent, three typefaces, two themes. Components carry real states so products feel consistent as the ecosystem grows.

        • Workspace structure. Navigation, content, and context stay in predictable places.
        • Dense where it helps. Technical surfaces show more; onboarding shows less.
        • Mobile by design. Panels collapse into focused views instead of shrinking.

        How we approach building

        Useful by design
        Each product starts from a task someone needs done. If a feature does not shorten that task, it waits.
        Built to evolve
        Products stay independently deployable, so one can change direction without forcing the rest to follow.
        Connected by engineering
        Authentication, APIs, and design tokens are shared where sharing reduces work and kept separate where it does not.
        Thoughtful about complexity
        We prefer plain architecture we can explain, and we write down the trade-offs we make.
